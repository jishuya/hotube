# HoTube

가족 사진과 영상을 비공개로 공유하는 PWA입니다.

## 가족별 공유 정책

공개 범위는 로그인한 사용자의 권한(`admin`, `sub-admin`, `user`)과 가족 구분(`mom`, `dad`)을 기준으로 판단합니다. 관리자·부관리자는 모든 미디어와 댓글을 볼 수 있습니다.

### 미디어 업로드

| 업로드하는 사용자 | 기본으로 선택되는 공유 가족 |
|---|---|
| 관리자(엄마)·부관리자(아빠) | 부부 |
| 엄마가족 일반 사용자(외할머니, 이모, 삼촌 등) | 엄마가족 |
| 아빠가족 일반 사용자(친할머니, 고모, 고모부 등) | 아빠가족 |

- 업로드 전에 공유 가족을 직접 변경할 수 있습니다. 업로드 완료 후에도 다음 입력의 기본값은 위 기준으로 돌아갑니다.
- 관리자·부관리자에게는 **부부** 옵션이 추가됩니다. 선택하면 양쪽 가족 공유가 해제되고 관리자·부관리자만 볼 수 있습니다.
- 사진, 영상, 유튜브 등록에 같은 규칙을 적용합니다.
- 일반 사용자는 공유받은 미디어와 본인이 올린 미디어를 볼 수 있습니다.

### 댓글 공개 범위와 색상

| 댓글 작성자 | 댓글을 볼 수 있는 사용자 | 댓글 표시 |
|---|---|---|
| 엄마가족 일반 사용자 | 엄마가족 + 관리자·부관리자 | 분홍색 ‘엄마가족’ 배지 |
| 아빠가족 일반 사용자 | 아빠가족 + 관리자·부관리자 | 파란색 ‘아빠가족’ 배지 |
| 관리자·부관리자 | 선택한 가족 + 관리자·부관리자 | 한쪽 가족은 해당 색상, 양쪽 가족은 보라색 ‘양쪽 가족’ 배지 |

- 일반 가족의 댓글 공개 범위는 본인 가족으로 고정되며, 다른 가족에게 공개하도록 변경할 수 없습니다. 서버에서도 같은 규칙을 적용합니다.
- 관리자·부관리자의 댓글은 기본적으로 본인 소속 가족에 공개됩니다(엄마가족 소속이면 엄마가족, 아빠가족 소속이면 아빠가족). 작성 시 다른 쪽 가족만 또는 양쪽 가족을 선택할 수 있으며, 등록 후에는 본인 가족 기본값으로 돌아갑니다.
- 댓글을 작성하거나 조회하려면 먼저 해당 미디어를 볼 권한이 있어야 합니다. 댓글 수에도 본인이 볼 수 있는 댓글만 포함됩니다.
- 예: 엄마가 양쪽 가족에 공유한 사진에 이모와 고모가 댓글을 달아도, 이모와 고모는 서로의 댓글을 볼 수 없습니다. 엄마와 아빠는 두 댓글 모두 볼 수 있습니다.
- 기존 일반 가족의 댓글도 백엔드 시작 시 작성 당시 가족 구분에 맞춰 공개 범위를 정리합니다.

### 댓글 알림

- 기존 알림 대상인 미디어 업로더와 해당 미디어의 댓글 작성자 중, 미디어와 새 댓글을 모두 볼 수 있는 사용자에게만 알림을 보냅니다. 새 댓글 작성자 본인은 제외합니다.
- 엄마가족 댓글은 아빠가족 일반 사용자에게, 아빠가족 댓글은 엄마가족 일반 사용자에게 알림을 보내지 않습니다.
- 선택한 가족 전원에게 일괄 발송하는 방식은 아닙니다. 푸시 알림은 사용자의 알림 설정도 따릅니다.

### 기타 가족 구분

- `etc` 사용자의 미디어 기본 공유 대상은 엄마가족 + 아빠가족입니다.
- `etc` 사용자의 댓글은 기타 가족과 관리자·부관리자에게 공개되며, 회색 ‘기타 가족’ 배지로 표시합니다.

## 구성

- Frontend: React 19, Vite, Tailwind CSS
- Backend: Express, PostgreSQL
- Media: 로컬 파일 저장소, FFmpeg
- Deployment: PM2, Cloudflare Tunnel

운영 환경에서는 `backend/src/server.js`가 API와 `frontend/dist` 정적 파일을 함께 제공합니다.

## 개발

```bash
npm run install:all
npm run dev
npm run dev:backend
```

## 검증 및 배포

미디어 수정에서 업로드한 사진·영상의 방향을 90도씩 보정할 수 있습니다. 보정값은 일반 보기와 전체보기에 적용되며 원본 파일은 변경하지 않습니다. YouTube 영상은 방향 보정 대상에서 제외됩니다. 서버 시작 시 `media.rotation` 열이 자동으로 추가됩니다. 수동 적용이 필요하면 [방향 보정 마이그레이션](docs/postgresql/add_media_rotation.sql)을 사용하세요.

```bash
npm run build
npm test --prefix backend
pm2 restart hotube-backend
curl http://localhost:5001/health
```

상세 운영 절차는 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)를 참고하세요.
